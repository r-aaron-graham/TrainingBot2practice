# Security reporting and scope

Report vulnerabilities privately through GitHub Security reporting when enabled. Otherwise request a private contact channel in an issue without including sensitive records or exploit details.

Evaluation files can contain confidential model responses. Keep real datasets outside the repository and apply appropriate access and retention controls. The CLI reads local JSON and prints a report. It performs no external requests. Large or untrusted files require resource limits in the deployment environment. The synthetic fixture provides limited evidence about actual model quality.
